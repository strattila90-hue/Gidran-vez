# Gidrán Hill Climb

A 2D hill-climb driving game starring a Gidrán-style armored 4x4 vehicle. Drive as far as you can across rolling terrain without flipping over or running out of fuel.

> **Unofficial project.** This is a hobby / training aid created for learning and fun. It is not affiliated with, endorsed by, or produced by any vehicle manufacturer or armed forces. The vehicle's look is a stylized drawing.

## Play

Open the game in a browser:

**https://strattila90-hue.github.io/Gidran-vez/**

## Install on your phone (Android)

1. Open the link above in Chrome.
2. Tap the three-dot menu (⋮).
3. Tap **Install app** (or **Add to Home screen**).
4. Launch the Gidrán icon from your home screen. It runs full screen and works offline after the first load.
